# IenjoyMatch 的个人网站

这是使用 GitHub Pages 托管的静态个人网站。网站入口为 `index.html`，样式位于 `style.css`，交互效果位于 `nav.js`、`glass.js` 和 `portrait-hdr.js`。

可以继续在本地或 GitHub 中修改这些文件；将修改提交到网站的发布分支后，GitHub Pages 会重新发布。头像图片和字体文件也需要随网页一同保留。
